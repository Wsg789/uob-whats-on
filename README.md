# whatson

Unofficial weekly listing of University of Birmingham society events, gathered from public society Instagram posts.

- `index.html`, `app.js`, `styles.css`: the listing page.
- `about.html`: what it is, and how societies can fix or remove a listing.
- `events.js`: the event list, replaced every week.
- `corrections.json`: manual corrections that the weekly update keeps.
- `posts/`: images published to Instagram.

Not affiliated with the University of Birmingham or the Guild of Students.
